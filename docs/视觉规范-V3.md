# 四象智投 · 视觉规范 V3（暖白 · 墨黑 · 焦橙）

日期：2026-11-25。适用于网页端全部页面：PC 优先，手机端见第 12 节。取代《设计原则与品牌调性》里的第 3、4、7、8 节（纸墨朱、宋体那一版）；品牌立场、焦虑与产品时刻、语气仍以那份文档为准。

本规范的每一条都已在 `frontend/` 里实现。**代码是准绳**：取值以 `frontend/src/styles/tokens.css` 为准，本文档与代码不一致时先核对代码，再回来改文档。

给开发会话的最短版本：

1. 颜色、圆角、投影、动效时长**只用变量**，不写新的色值。
2. **橙色不表示涨跌**。红绿只用在带正负号的数字和图形上。
3. **墨黑大卡一屏只出现一次**，留给这一屏最重要的东西。
4. **主按钮一屏只放一个**，橙底白字。
5. 页面上的数字必须来自接口；动效不得显示不存在的数字。
6. 写新页面前先看第 6 节“组件”，能复用就不新造。

---

## 1. 设计思路

**不卖收益，卖确定感。** 界面要让人觉得踏实，而不是兴奋。

- **暖白铺底（约 75%）**：大面积留白，卡片是白色，页面底是暖白。
- **墨黑（约 15%）**：文字、当前导航、以及“结论”这类最重要内容的深色大卡。
- **焦橙（约 10%）**：只给四样东西——主按钮、小四、概率点阵、封存印。橙色出现的地方，就是“小四”和“你的判断”所在的地方。
- **先结论，后证据**：每个答案先给一个大数字和一句人话，再给分布、证据和口径。
- **数字有出处**：结论旁边能看到样本数、数据截至哪天、按什么口径。
- **斜纹表示“还没发生”**：进度条没走完的部分、待封存的印、等待揭晓的结果。
- **安静**：不做闪烁、倒计时、红点轰炸。动效只留给三个时刻（回答出现、封存、揭晓）。

### 2.5 涨跌

| 变量 | 取值 | 用在哪 |
| --- | --- | --- |
| `--up` / `--up-soft` | `#E0203A` / `#FDE8EB` | 涨：数字、柱子、K 线；浅色做涨跌小标签的底 |
| `--down` / `--down-soft` | `#0A8754` / `#E3F4EC` | 跌 |
| `--flat` | `#A39A94` | 中性（如“涨了但没回本”） |

**规则（必须遵守）：**

- 红涨绿跌，A 股习惯。
- 红色特意选了偏冷的正红，和焦橙拉开。**不要把 `--accent` 用在任何带涨跌含义的地方**，也不要把 `--up` 当强调色用。
- 概率不是涨跌：概率数字用墨黑（浅底）或暖白（深色卡），配橙色点阵。
- 错误提示目前用 `--up`（沿用），只用于表单和读取失败的文字。

### 2.6 图表线色

均线 `--series-1/2/3` = `#190300` / `#2A78D6` / `#8B5CF6`。不用黄和橙，避免和品牌色、涨跌色混淆。

## 3. 字体

- **数字和拉丁字母**：Outfit 可变字体，自托管（`frontend/public/fonts/outfit-latin-wght.woff2`，32 KB，OFL 许可）。
- **中文**：系统黑体（苹方 / 鸿蒙 / 微软雅黑），不另外下载。
- 统一用 `var(--font)`。全站默认开 `font-variant-numeric: tabular-nums`，数字等宽对齐。
- 不再使用宋体。`noto-serif-sc-600-subset.woff2` 已不引用，文件暂留。
- 字重只用 400（正文）、500（标签、次要强调）、600（标题、数字）、700（品牌名、登录页大标题、印章）。

## 4. 间距、圆角、投影

**间距**：4 的倍数。常用 8 / 12 / 16 / 20 / 24 / 32。

| 场景 | 取值 |
| --- | --- |
| 卡片与卡片之间 | 20（紧凑网格用 12） |
| 卡片内边距 | 20 × 24（小卡 18 × 20，带图表的 24 × 28，深色主卡 28–36） |
| 页面左右留白 | 32 |
| 页面内容最大宽度 | 1280（详情类 880–960，报告类 1080） |
| 页头与内容 | 20–24 |

**圆角**

| 变量 | 取值 | 用在哪 |
| --- | --- | --- |
| `--r-sm` | 10 | 小标签、表格内小块、小输入框 |
| `--r` | 14 | 输入框、导航项、列表项悬停底 |
| `--r-lg` | 20 | 卡片 |
| `--r-xl` | 28 | 深色主卡、登录卡 |
| `--r-pill` | 999 | 所有按钮、分段选择、标签、搜索框、进度条 |

侧边导航外框 24，登录页左侧大块 32，封存印 28%（相对自身）。

**投影**

| 变量 | 用在哪 |
| --- | --- |
| `--shadow` | 普通卡片：很轻，带一点暖色 |
| `--lift` | 深色主卡、下拉、悬停抬起的卡片 |
| `--glow` | 橙色的光：主按钮、封存印、“到期了，点开揭晓” |

卡片一律 `1px solid var(--line)` + `--shadow`。不要自己写新的投影。

## 5. 页面骨架

文件：`frontend/src/app/AppLayout.tsx`、`AppLayout.css`。

- **左侧导航**：宽 236，白色浮起的圆角块（距窗口边 12），吸顶。内容从上到下：品牌标识、四项菜单（问小四 / 我的判断 / 验证方法 / 行情）、小四 + “日线截至某天”。
- **页内二级切换** `SubNav`：“问小四”下面是 提问 / 聊过的 / 角色，“验证方法”下面是 方法库 / 我验证过的，“行情”下面是 自选 / 个股 / 大盘。样子和分段选择一样，放在页头上方。主导航不再加项，新页面优先挂到这四项下面。
- **当前菜单**：墨黑底、暖白字、图标变橙。黑色底块在菜单项之间滑动（360ms）。
- **右侧**：顶栏（全局股票搜索 + 用户）吸顶、半透明毛玻璃；下面是页面内容。
- **页面背景**：暖白，右上角一团很淡的橙色光，固定不随滚动。
- **窗口窄于 1080**：导航收成 76 宽的一列图标，双栏页面变单栏。
- **窗口窄于 760（手机）**：导航换成底部标签栏，见第 12 节。

**页面内的常见布局**

| 布局 | 例子 | 写法 |
| --- | --- | --- |
| 主栏 + 右侧栏 | 首页、回答页、看盘、形态首页 | `grid-template-columns: minmax(0, 1fr) 300–360px; gap: 20px`；右栏可吸顶（`top: 84px`） |
| 单栏居中 | 我的判断、判断详情 | `max-width: 880–960px; margin: 0 auto` |
| 单栏靠左 | 形态报告、新建、后台 | `max-width: 1080px` |

每页以页头开始：`<header class="page-head"><h1>…</h1><p class="muted">一句话说明</p></header>`。

## 6. 组件

写新界面前先在这里找。全局样式在 `frontend/src/styles/global.css`。

### 6.1 按钮 `.btn`

| 类 | 样子 | 什么时候用 |
| --- | --- | --- |
| `.btn.primary` | 橙底、白字、橙色光 | **一屏一个**，最重要的那个动作：问小四、封存、运行 |
| `.btn.dark` | 墨黑底、暖白字 | 第二重要，或主动作完成后的下一步（“去我的判断里看”） |
| `.btn` | 白底、细边 | 其余所有动作 |
| `.btn[aria-pressed='true']` | 墨黑底 | 开关型按钮的“已打开” |
| 加 `.lg` | 高 46、字 15 | 页面级的主动作 |

全部是全圆角。禁用态透明度 45%，主按钮禁用时去掉光。

### 6.2 分段选择 `.seg`

凹槽（`--bg-deep`）里一个白色滑块。用于互斥切换（复权方式、时间范围、登录 / 注册）。选中项用 `aria-pressed='true'` 或 `aria-selected='true'`。

首页提问面板里的期限选择（`.ask-select`）是同一形态的加强版：选中项墨黑底。

### 6.3 标签 `.tag`

| 类 | 样子 | 用在哪 |
| --- | --- | --- |
| `.tag` | 浅橙底、深橙字 | 状态、提示（“已调整”“仅 A”） |
| `.tag.plain` | 凹槽色底、灰字 | 中性信息（日期、数据版本、“对照”） |
| `.tag.night` | 墨黑底、暖白字 | 类别（“问期权”“小四 · 问个股”） |

涨跌小标签用 `.chg` + `.up` / `.down`（浅红 / 浅绿底）。

### 6.4 卡片 `.card` 与 `.card-title`

白底、细边、圆角 20、轻投影。标题行用 `.card-title`：左边标题（16，600），右边放说明（`.muted`，12）或分段选择。

### 6.5 深色主卡

`background: var(--ember), var(--night); color: var(--on-night); border-radius: var(--r-xl); box-shadow: var(--lift)`。

**一屏只出现一次。** 现在用在：首页提问区、回答页和形态报告的结论卡（`Verdict`）、判断详情的“当时的判断”、登录页左侧、看盘页的“拿这只票问小四”、形态首页的当前入口、大盘页选中的指数。新增使用前先想清楚它是不是这一屏最重要的东西。

### 6.6 结论卡 `Verdict`

文件：`frontend/src/components/Verdict.tsx`。先结论的标准形态：小标签 → 大数字（128）→ 百点图 + 说明 → 一句大白话（20）→ 一行补充（13）。

- `dots` 传 0–100：显示 10×10 的点阵，“每 100 次里有 N 次”。
- `tag`：右上角一句结论（“和随便买差不多”）。
- `pending`：新结果还在算时把旧内容压暗。
- 数值变化时数字从旧值滚到新值，点阵多亮或少亮几颗。**第一次出现时直接显示，不从 0 滚。**

### 6.7 封存印 `Seal`

文件：`frontend/src/components/Seal.tsx`。焦橙圆角方章，白字，歪 8 度，内圈虚线。四象智投的标志性符号。

- 文字固定两行两个字一组：“已 / 封存”“已 / 揭晓”“已 / 到期”“待 / 封存”。
- `ghost`：斜纹底、灰字，表示还没封存。
- `stamp`：盖下去的动效，只在**刚刚封存成功**时用。
- `className="flip"`：翻面，只在揭晓时用。
- 常用尺寸：列表 46，侧栏 / 首页 48–52，回答页 72，详情页 84。

### 6.8 小四

文件：`frontend/src/components/xiaosi/`。**外形不改。** 颜色是品牌橙（`ResearchPet.tsx` 里的 `ink`）。

| 场景 | 尺寸 | 状态 |
| --- | --- | --- |
| 首页 / 登录页主视觉 | 140–168 | `idle`，首页开 `followPointer`（眼睛跟鼠标） |
| 等待回答 | 120 | `researching` |
| 小四说话的卡片 | 52 | 平时 `idle`；重新计算时 `thinking`；封存成功 / 揭晓时短暂 `complete`（眨眼） |
| 导航底部、看盘页 | 40–44 | `idle` |
| 出错 | 96 | `error` |

- 小四**陪在结论旁边，不抢结论的位置**。结论永远在结论卡里。
- 小四说的话放在自己的卡片里，15 号字、行高 1.9，墨黑。
- 深色卡上的大号小四加一层橙色投影：`filter: drop-shadow(0 18px 30px #fb5e0d66)`。

### 6.9 进度条 `.progress`

高 8，全圆角。已走部分焦橙，未走部分斜纹。加 `.live` 时斜纹缓慢流动（5 秒一轮），只用在**封存中**的判断上。`.progress.night` 把填充换成墨黑，用于和橙色那条做对照。

### 6.11 表格

类：`.sum-table`（统计）、`.list-table`（可点的列表）、`.reason-table`、`.fin-table`、`.admin-table`。

### 6.13 状态

- 加载、空、出错的文字：`.state`（居中、`--muted`），出错加 `.error`。
- 空状态尽量给一个“待封存”的 ghost 印或小四，加一句话说明下一步做什么，再给一个按钮。
- 提示条：`.lineage`（浅橙底）、`.warn`（橙底 + 图标）。

### 6.14 品牌标识 `.brand-mark`

2×2 的四个小方块（9px、圆角 3、间距 3），左上右下墨黑，右上左下焦橙。深色底上加 `.on-night`，墨黑换成暖白。

### 6.15 表态 `.ask-stance`

封存前让用户自己表个态，只点一下：三个全圆角小按钮（个股：我觉得会涨 / 我觉得不会涨 / 听小四的；期权：能回本 / 回不了本 / 听小四的）。选中的墨黑底。**没选之前主按钮不可点**，文字是“先选一个看法”。文案和判断口径在 `frontend/src/lib/stance.ts`，不要在页面里另写。

揭晓页用 `.jd-views` 把“你当时的看法”和“小四的倾向”并排放在“当时 / 实际”下面。**对错不是涨跌，不用红绿**：对了用墨黑实底小标签，没对用凹槽灰。对错只在揭晓之后显示。

### 6.16 自选

- 加自选按钮 `WatchStar`：放在股票名旁边的小号全圆角按钮，已自选时浅橙底。
- 首页自选卡 `WatchlistCard`：每只一行，名称 + 收盘价 + 涨跌，下面一条橙色条表示“和现在相似的时候之后在涨的比例”，条上一道墨黑竖线是它平时的比例。两列排，手机单列。

### 6.17 方法库卡片 `.tpl-card`

标题、一句说明、一个 44 号的大数字（在涨的比例）加一句结论标签（比随便买略好 / 差不多 / 还差）。“略好”用橙色标签，其余用中性标签。还在算的时候显示进度条。卡片底部一行小字和“调参数自己算”。

### 6.18 分享卡 `ShareCard`

竖版 3:4（1080×1440），用画布画成图片，弹层里预览和保存。墨黑底 + 橙色光晕 + 封存印，一个大数字。封存时一张（小四给的概率、我的看法、哪天揭晓），揭晓后一张（当时 vs 实际、我说对没有）。**卡片上只有历史统计和已经发生的结果**，不出现收益承诺，不放示意数字。

### 6.19 相似的时候 `SimilarTimes`

文件：`frontend/src/components/SimilarTimes.tsx`。回答页里的走势图（对数坐标，2007 年起收盘线，墨黑偏灰 1.5px）上标出每个相似的起点：之后涨的红点、跌的绿点（直径 8，白描边）。选中的点放大到 14，并用浅焦橙底标出之后 N 个交易日的区间；下方一条回放：日期、之后涨跌、走势小图，左右箭头逐个翻。红绿表示的是“之后的结果”，符合“红绿只用于涨跌”。

### 6.20 期权费曲线 `FeeCurve`

文件：`frontend/src/components/FeeCurve.tsx`。横轴期权费 1%–15%，纵轴回本比例 0–100%。焦橙实线 2.5px 是“和现在相似的时候”，灰色虚线是“随便哪天买”；墨黑竖线标“你问的”价位。点图上任意位置按该价位重问。图下一行大白话读数（回本过半的最高价位、扣费后平均不亏的最高价位）。

### 6.21 两只对比 `.acmp-*`

文件：`frontend/src/features/ask/AskComparePage.tsx`。两张白卡并排，各一个大数字（72）+ 焦橙进度条 + 四行数据；在涨比例明显更高的一张加浅橙边和 `.tag`“在涨的比例更高”，差距小于 3 个百分点时都不标。这一页没有墨黑大卡（两边地位相同）。

### 6.19 群聊

文件：`frontend/src/features/rooms/`。手机是主要场景，PC 上居中一栏（最宽 760）。

- **头像** `Avatar`：不用真人照片。圆形，角色自己的固定颜色（角色卡里的 `color`），中间是名字的第一个字。小四是焦橙。
- **气泡** `.bubble`：白底细边，左上角是直角（4），其余圆角 18；同一个人连发的后几条四角全圆。字号 15，行高 1.7。
  - 小四（主持人）：浅橙底，一眼分得出。
  - 用户自己：靠右，墨黑底、暖白字。
  - 系统提示（某某被请出了群）：居中的小号灰字胶囊。
- **名字行**：名字 13 号加粗，后面跟一个小标签写他“看什么”。
- **引用**：回别人的话时，气泡上方一行小字“回 某某：……”，左边一道竖线。
- **正在输入**：三个小圆点上下波动。
- **数据卡** `.data-card`：暖白底、虚线边、圆角 14，挂在消息下面。数字来自引擎，不是模型写的。概率用自选卡同一种条：橙色是“相似的时候”，墨黑竖线是平时。
- **底部**：一行 @ 谁的小按钮，加一个主按钮“让他们接着聊”（橙色）；下面是全圆角的输入框和墨黑的发送按钮。吸在页面底部，手机上吸在标签栏上方。
- **角色页**：每人一张卡，卡顶一道 4px 的角色色条。
- 页面上没有报错状态：后端出的问题都已经变成台词或被跳过了。

## 7. 动效

**原则**：接住焦虑，不制造焦虑。不闪烁、不倒计时、不循环吸引注意。所有动效都要尊重“减少动态效果”的系统设置（`prefers-reduced-motion`）。JS 里编排的动效先调 `motionOff()`（`frontend/src/lib/motion.ts`）。

**动效不得显示不存在的数字。** 数字只能从一个真实值过渡到另一个真实值；不做从 0 滚到结果的效果。

### 7.1 基础取值

| 变量 / 类 | 取值 | 用在哪 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.2, .7, .2, 1)` | 全部过渡 |
| `--t-fast` | 180ms | 悬停、按下、聚焦 |
| `--t` | 320ms | 出现、切换、压暗 |
| `.fade-in` | 上移 8px 淡入，320ms | 页头、单个区块出现 |
| `.stagger` | 子元素依次 `.fade-in`，每个晚 50ms（第 6 个起不再加） | 一组卡片出现 |

悬停反馈：卡片上移 1–2px + 边框加深或变橙；按钮按下下移 1px。

### 7.2 三个有编排的时刻

**回答出现**（`Verdict`、`Distribution`）

- 点阵从第一颗起逐个点亮（每颗晚 7ms）。
- 分布图柱子从零线长出来（500ms，每根晚 14ms），回本线随后落下。
- “接着问”时页面不清空：旧结果压暗到 45–50%，新结果到了，数字用 640ms 从旧值滚到新值，点阵增减。

**封存**（`AnswerPage.tsx` 的 `SealPanel`）

- **只在服务端确认封存成功后播放。**
- 按钮收成一块橙色，620ms 飞到右上角印章的位置。
- 印章盖下（420ms，从 1.9 倍缩到 1 倍），一圈印泥向外扩散，卡片下沉 4px 再回弹。
- 小四眨眼；导航里“我的判断”的数字跳一下。

**揭晓**（`JudgmentPage.tsx`）

- 第一次打开到期的判断时播放一次；之后直接看结果，页面上有“再看一遍揭晓”。“看没看过”记在浏览器本地（`sixiang.revealed`）。
- 停 700ms：结果盖着斜纹封条，显示“?”。
- 画线 1900ms：走势线从封存那天画到到期日，画在“当时估计的正常范围”色带里。画的是真实路径。
- 揭开 700ms：封条从左到右揭开，露出真实涨跌；印章翻面成“已揭晓”（500ms），小四眨眼，它的话换成复盘。
- 列表和首页里，到期但没点开过的判断**不提前显示结果**，只显示“到期了，点开揭晓”。

### 7.3 其他

- 导航选中块滑动 360ms。
- 封存中的进度条斜纹流动 5 秒一轮。
- 首页小四眼睛跟鼠标；选好股票眨眼；鼠标移到“问小四”按钮上，小四往提问框凑一点（400ms）。
- 等待回答时，小四轮流说它真的在做的三件事（1.5 秒一句），不做假的进度条。

## 8. 图表

- **K 线**（`KLineChart.tsx`）：红涨空心、绿跌实心；均线三条按 2.6 节配色，线宽 1.2；成交量红绿半透明；标注入选日用橙色图钉。
- **年度柱图**（`YearChart.tsx`）：正红负绿，柱顶圆角 6。
- **走势路径**（判断详情）：墨黑线宽 2；“正常范围”用 `--accent-softer` 色带；终点一个红或绿的圆点。
- 提示框统一：白底、细边、圆角 12、内边距 10 × 14、12 号字。
- 图表里的颜色从 `palette.ts` 取，不在组件里写色值。

## 9. 文案

沿用《设计原则与品牌调性》第 5 节，补充几条和界面直接相关的：

- 尽量大白话。说“运气最差的十分之一”，不说“P10”；说“比随便买”，不说“超额收益”。
- 先说人话，再给数字的口径。口径用小字放在下面。
- 敢说“不灵”“差不多”“样本太少”。不说“必涨”“稳赚”。
- 每个结论附近有一句“以上是历史统计，不构成买卖建议”。
- 按钮写动作：“问小四”“封存这个判断”“去验证我的方法”。
- 数字和中文之间留一个空格（“3 个月”“29 个”）。

## 10. 不要做的事

- 不要写新的色值、投影、圆角，用变量。
- 不要用橙色表示涨跌，不要用红色做强调。
- 不要在橙底上放小号细字或长段文字（白字在橙底上对比度只有 3.1）。
- 不要在一屏里放两张深色主卡，或两个主按钮。
- 不要为了好看放示意数字。未登录页面拿不到数据，就不放数字。
- 不要做从 0 滚动到结果的数字动画。
- 不要加倒计时、闪烁、红点、自动弹出的提醒。
- 不要把小四放在结论的位置上，也不要改它的外形。
- 不要用宋体。

## 12. 手机端

同一套代码、同一套变量，不单独做手机版页面。**断点是 760px**：`@media (max-width: 760px)`，写在各自的 css 文件末尾（标着“手机端”）。新页面做完后要在 375 宽度下看一遍，不能出现横向滚动。

### 12.1 外壳

- **底部标签栏**取代左侧导航：4 项（问小四 / 判断 / 方法 / 行情），每项高 52，图标 20 + 11 号字。当前项仍是墨黑底块、图标变橙，底块在项之间滑动。封存中的数量显示在“判断”的右上角。
- 标签栏白色半透明毛玻璃，顶部圆角 20，底部留出 `env(safe-area-inset-bottom)`（刘海屏的横条）。
- **顶栏**只留三样：品牌标识（点了回首页）、股票搜索、头像和退出。用户名和“管理”的文字收起，只留图标。
- 页面左右留白 16，底部留 96 给标签栏。
- “日线截至某天”在手机上不在导航里了，首页的“小四用的数据”和每个回答的“数据截至”里仍然能看到。

### 12.2 通用规则

| 规则 | 取值 | 为什么 |
| --- | --- | --- |
| 输入框字号 | 不小于 16 | iPhone 上小于 16 的输入框点进去会自动放大页面 |
| 可点区域 | 按钮至少 40 高（大按钮 48），分段选择 36，标签栏 52 | 手指点得准 |
| 卡片 | 内边距 16，圆角 18；深色主卡圆角 24 | 屏幕窄，留给内容 |
| 卡片间距 | 12–14 | |
| 页标题 | 24 | |
| 主按钮 | 占满整行 | 拇指够得着 |
| 表格 | 不改成卡片，横向滑动；滑动区域延伸到屏幕边 | 数字要对齐着比 |
| 分段选择 | 放不下就横向滑动，不换行 | |
| 悬停效果 | 触屏上不做“抬起” | 手指点完会停在悬停状态 |
| 需要悬停才能看的信息 | 改成点一下 | 分布图：点柱子或色条看次数 |

### 12.3 各页的排法

- **首页**：问候 → 深色提问卡 → 最近验证过的方法 → 我的判断 → 大盘 → 数据。深色卡里小四缩到 76 放在右上角，说明文字收起。提问面板一行放一段（股票 / 期限 / 问句），句子里的逗号不显示。
- **回答页**：把右栏拆开穿插进正文，顺序是 **结论 → 小四说 → 三个关键数 → 分布图 → 封存 → 证据 → 怎么算的**。封存放在看完分布之后、证据之前：看懂了就能封存，不用滑到底。结论卡大数字 88，点阵在数字下面。三个关键数仍然一行三个（数字 22）。问题的条件标签横向滑动。
- **我的判断**：每条判断上面是印章 + 名称，下面是进度或结果，整条可点。
- **判断详情 / 揭晓**：“当时的判断”和“实际结果”**仍然并排**（数字 40），这是这一页的全部意思，不能上下叠。印章 60。揭晓的过程和 PC 一样。
- **登录页**：上面是压缩后的深色块（一句“心里有数，再出手”+ 小四），下面直接是登录表单，一屏内能点到“进入”。三种问法和页脚收起。
- **形态**：模板卡单列；报告的三个统计格一行三个；参数两列；运行按钮占满整行。
- **看盘 / 大盘**：单列；K 线高 340 / 300；指数卡一行两个。
