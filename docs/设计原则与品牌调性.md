# 四象智投 · 设计原则与品牌调性 V1

日期：2026-11-25。适用于全部页面、文案、小四与对外传播物料。与《产品与架构说明》配套。

## 1. 我们卖的是什么

**不卖收益，卖确定感。**

股民最深的焦虑不是“会不会亏”，而是“不知道自己在干什么”：消息不知道该不该信，方法不知道灵不灵，买了之后不知道该怎么想，亏了不知道是运气还是方法。我们无法、也不承诺让用户赚钱；我们给的是“心里有数”：

- 概率：这件事历史上发生过多少次、结果分布怎样；
- 证据：每个数字都能追到来源；
- 封存与揭晓：判断交给小四保管，到期自动揭晓，不必盯盘；
- 档案：看见自己的判断准确率与成长。

**接住焦虑，不制造焦虑。** 不用“暴涨”“错过就亏”“主力在收割你”之类的话术；不做制造紧迫感的倒计时、红点轰炸和行情推送。焦虑会转化为频繁交易，亏损的用户不会留下，私域口碑也会反噬。

品牌一句话：**心里有数，再出手。**

## 2. 焦虑与产品时刻

| 焦虑 | 用户原话 | 我们给的确定感 | 产品时刻 |
| --- | --- | --- | --- |
| 怕错过 | 大家都在说这只，要不要上？ | 类似情况之后上涨的概率、最差会怎样 | 问个股 |
| 怕被收割 | 这个期权费是不是太贵？ | 回本概率与最坏情形 | 问期权 |
| 自我怀疑 | 我这招到底灵不灵？ | 17 年数据验证，对照随机买入 | 问方法 |
| 买后不安 | 买了就天天盯盘 | 判断已封存，到期自动揭晓 | 封存 / 揭晓 |
| 不知错在哪 | 亏了是运气还是方法？ | 判断档案与准确率 | 我的档案 |

**留存靠仪式，不靠推送**：每日盘后小四简报（3 分钟读完）、到期揭晓、个人档案。“揭晓”是产品里最有戏剧性的时刻，值得最用心的设计。

## 3. 视觉原则

> 2026-11-25 更新：视觉改为 V3（暖白、墨黑、焦橙），原来的“纸、墨、一点朱 + 宋体”不再使用。
> 具体取值、组件和动效见 [视觉规范 V3](视觉规范-V3.md)，以那份文档和 `frontend/src/styles/tokens.css` 为准。

仍然成立的原则：

1. **克制**：一屏只讲一件事，大面积留白。颜色只有暖白、墨黑、一点焦橙。
2. **先结论，后证据**：每个答案先给一个大号数字和一句人话，再给分布图、证据和口径。
3. **数字有出处**：结论旁边永远能看到“样本多少、数据截至哪天、按什么口径”。
4. **小四是灵魂**：思考、取证、给出结论、揭晓时有不同状态；空状态和加载由小四陪伴，但小四不抢结论的位置。
5. **封存印**：“已封存”“已揭晓”用焦橙方印表达，是四象智投的标志性符号。
6. **橙色不表示涨跌**：红涨绿跌只用在带正负号的数字和图形上；概率用墨黑或暖白数字配橙色点阵。

## 5. 语气

- 冷静、具体、像一位靠谱的研究员朋友。
- 用数字说话，再用一句人话解释：“约每 3 次出现 1 次”，而不是“胜率 31.4%”。
- 敢说“不灵”“不确定”“样本太少”；不说“必涨”“稳赚”“抄底良机”。
- 结尾不给买卖指令，给“下一步可以看什么”。

## 6. 传播物料

研究分享卡是私域里最好的广告：竖版 3:4，一个大数字，一张极简分布图，封存印，底部是“四象智投”和邀请标识。卡片只呈现历史统计与口径，不出现收益承诺。

分享卡和揭晓卡还没有按 V3 重做，动手前先对照 [视觉规范 V3](视觉规范-V3.md)。
