# 四象智投 · 设计原则与品牌调性 V1

日期：2026-11-25。适用于全部页面、文案、小四与对外传播物料。与《产品与架构说明》配套。

## 1. 我们卖的是什么

**不卖收益，卖确定感。**

股民最深的焦虑不是“会不会亏”，而是“不知道自己在干什么”：消息不知道该不该信，方法不知道灵不灵，买了之后不知道该怎么想，亏了不知道是运气还是方法。我们无法、也不承诺让用户赚钱；我们给的是“心里有数”：

- 概率：这件事历史上发生过多少次、结果分布怎样；
- 证据：每个数字都能追到来源；
- 封存与揭晓：判断交给小四保管，到期自动揭晓，不必盯盘；
- 档案：看见自己的判断准确率与成长。

**接住焦虑，不制造焦虑。** 不用“暴涨”“错过就亏”“主力在收割你”之类的话术；不做制造紧迫感的倒计时、红点轰炸和行情推送。焦虑会转化为频繁交易，亏损的用户不会留下，私域口碑也会反噬。

品牌一句话：**心里有数，再出手。**

## 2. 焦虑与产品时刻

| 焦虑 | 用户原话 | 我们给的确定感 | 产品时刻 |
| --- | --- | --- | --- |
| 怕错过 | 大家都在说这只，要不要上？ | 类似情况之后上涨的概率、最差会怎样 | 问个股 |
| 怕被收割 | 这个期权费是不是太贵？ | 回本概率与最坏情形 | 问期权 |
| 自我怀疑 | 我这招到底灵不灵？ | 17 年数据验证，对照随机买入 | 问方法 |
| 买后不安 | 买了就天天盯盘 | 判断已封存，到期自动揭晓 | 封存 / 揭晓 |
| 不知错在哪 | 亏了是运气还是方法？ | 判断档案与准确率 | 我的档案 |

**留存靠仪式，不靠推送**：每日盘后小四简报（3 分钟读完）、到期揭晓、个人档案。“揭晓”是产品里最有戏剧性的时刻，值得最用心的设计。

## 3. 视觉原则

1. **克制**：一屏只讲一件事。大面积留白；颜色只有纸、墨、一点朱。越少越贵。
2. **研究刊物的排版**：标题与关键数字用宋体（思源宋体 Noto Serif SC），正文用无衬线体，数字等宽对齐。用细线分隔，少用卡片和阴影。
3. **先结论，后证据**：每个答案先给一个大号数字和一句人话，再给分布图、证据和口径。
4. **数字有出处**：结论旁边永远能看到“样本多少、数据截至哪天、按什么口径”。
5. **小四是灵魂**：思考、取证、给出结论、揭晓时有不同状态；空状态和加载由小四陪伴，但小四不抢结论的位置。
6. **朱印**：“已封存”“已揭晓”用朱红方印表达，是四象智投的标志性符号。

## 4. 设计变量

| 类别 | 取值 |
| --- | --- |
| 纸 | 背景 `#f7f5f0`，卡面 `#fffdf9`，深纸 `#efece4` |
| 墨 | 标题 `#1d211e`，正文 `#3a3f3b`，次要 `#7b8179`，细线 `#e2ded4` |
| 朱 | `#c8442f`（只用于印章、回本线等关键强调；不做按钮底色），浅朱 `#f6e7e1` |
| 按钮 | 主按钮墨色实底 `#1d211e`，次按钮细墨线框；直角或 6px 圆角 |
| 涨跌 | 涨 `#c23a30`，跌 `#2a7a4b`，中性 `#948e83`（红涨绿跌；数据里的红色只表示涨） |
| 字体 | 标题与大数字：Noto Serif SC 600/700；正文：系统无衬线（PingFang SC / Microsoft YaHei）；数字 tabular-nums |
| 字号 | 12 / 14 / 16 / 20 / 28 / 40 / 64（大数字） |
| 间距 | 8 的倍数；正文栏宽 640–720px |
| 圆角 | 6（控件）/ 14（卡片）/ 0（印章） |
| 动效 | 220ms ease-out；只用于状态变化与揭晓，不做装饰性动画 |

上线时自托管思源宋体的常用字子集，保证所有用户看到同样的字体。

## 5. 语气

- 冷静、具体、像一位靠谱的研究员朋友。
- 用数字说话，再用一句人话解释：“约每 3 次出现 1 次”，而不是“胜率 31.4%”。
- 敢说“不灵”“不确定”“样本太少”；不说“必涨”“稳赚”“抄底良机”。
- 结尾不给买卖指令，给“下一步可以看什么”。

## 6. 传播物料

研究分享卡是私域里最好的广告：竖版 3:4，纸色底，宋体标题，一个大数字，一张极简分布图，朱印，底部是“四象智投”和邀请标识。卡片只呈现历史统计与口径，不出现收益承诺。

## 7. 样板

`prototypes/design-v2/`（入口 index.html）：登录首页、小四回答页（含封存）、分享卡与揭晓卡。样板为示意数据，确认后统一改造正式页面。

改造正式页面时：设计变量替换 `frontend/src/styles/tokens.css`；标题与大数字改用宋体；卡片改为细线分隔的版式；主按钮改墨色；新增朱印组件。

## 8. 已应用到正式页面（2026-11-25，PC 端）

- 设计变量：`frontend/src/styles/tokens.css`（纸墨朱、4px 圆角、细线、纸纹）；图表颜色 `frontend/src/lib/palette.ts`（ECharts 无法读 CSS 变量，两处须同步）。
- 字体：自托管思源宋体 600 字重子集 `frontend/public/fonts/`（GB2312 一级常用字 + 源码用字，688 KB，OFL 许可随附）；生僻字回退系统宋体。新增界面文字含生僻字时需重新生成子集。
- 组件：`Seal`（朱印）、`Verdict`（大数字 + 百点图 + 一句大白话）。
- 页面：登录首页、问小四首页、形态报告（先结论：“大约每 10 次有 N 次在涨，比同一天随便买……”，再条件、统计、年度、今日符合、案例）、形态首页、看盘、大盘、管理后台统一新样式；导航改为 问小四 / 看盘 / 形态 / 我的研究 / 大盘。
- 报告结论规则：与同日随便买相比差距小于 0.2 个百分点时说“差不多”；样本少于 100 次时提示参考价值有限。
- 手机端暂不专门适配（PC 优先）。
